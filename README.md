# 🌼 Poovum Codeum 

Welcome to **Poovum Codeum**, a digital Pookalam (floral carpet) creator built for the modern web! Celebrate the spirit of Onam by crafting stunning, intricate, and perfectly symmetrical Pookalams right in your browser—without needing real flowers! 

With its suite of advanced geometric and drawing tools, Poovum Codeum makes it easy for anyone to create first-prize-winning floral designs and export them as high-quality images.

![Poovum Codeum](https://raw.githubusercontent.com/ARJYUN/Poovum-Koodum/main/public/flowers/1.png)

## ✨ Features

- 🌸 **23 Authentic Flowers & Leaves:** Select from a curated library of digital floral assets.
- 🪄 **Magic Auto-Generator:** Instantly generate mathematically perfect, dense, 9-ring Pookalams with a single click.
- ❄️ **Mandala Tool:** Draw with 8-fold radial symmetry to easily create stunning, flawless geometric patterns.
- ⬡ **Polygon Shape Tool:** Instantly drop perfect hexagonal flower outlines.
- ✏️ **Advanced Drawing Tools:** Includes Brush, Pen (curved paths), Lines, and Eraser.
- 📱 **Mobile Responsive:** A fluid, app-like UI that works perfectly on touch devices (with Pointer Events).
- 💾 **High-Resolution Export:** Export your creations as crisp, transparent, high-res PNG images for sharing.
- 🎨 **Multiple Canvas Sizes & Backgrounds:** Choose between Small, Medium, and Large canvases, and toggle various floor textures.

## 🚀 Tech Stack

- **React 18** (with Vite)
- **Tailwind CSS** (for beautiful, utility-first styling)
- **Zustand** (for blazing-fast, centralized state management)
- **Lucide React** (for crisp UI icons)
- **html-to-image** (for seamless high-quality canvas exporting)
- **React Router** (HashRouter for flawless static hosting)

## 🛠️ Local Setup Instructions

Want to run this project on your own machine? It's incredibly easy!

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### 1. Clone the repository
```bash
git clone https://github.com/ARJYUN/Poovum-Koodum.git
cd Poovum-Koodum/poovum-codeum
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start the Development Server
```bash
npm run dev
```
The app will instantly start locally (usually on `http://localhost:5173`).

### 4. Build for Production
To create an optimized production build:
```bash
npm run build
```
The compiled files will be located in the `dist` folder, ready to be deployed to GitHub Pages, Vercel, Netlify, or any static host!

## 💡 How to Use

1. **Pick a Flower**: Tap any flower from the right-hand asset panel.
2. **Choose a Tool**: From the left toolbar, pick the **Mandala tool** (the snowflake icon) for instant symmetry, or the **Brush** for freehand drawing.
3. **Draw**: Click and drag on the canvas!
4. **Auto-Generate**: Feeling uninspired? Click the **Magic Wand** (yellow button) on the left sidebar to generate a randomized masterpiece.
5. **Export**: Click the **Export** button at the top to save a high-resolution PNG to your device.
